Guía Completa de Configuración en Cisco Packet Tracer

Solución Técnica de Seguridad de Puerto (Port Security) y Enrutamiento Dinámico RIPv2

Topología Multisede Cisco IOS Commands CCNA Security & Routing

1. Resumen de Requerimientos y Estrategia Técnica

Esta guía detalla los comandos específicos en Cisco IOS para resolver los 7 requerimientos de seguridad en switches y la interconexión mediante RIPv2 en la topología dada.

Punto Requerimiento Mecanismo de Solución en Cisco IOS
1 Restricción de equipos externos en Switches switchport port-security + maximum 1 + mac-address sticky
2 Protección del puerto Servidor DNS (Cúcuta) Port Security estático/sticky en Fa0/2 de Switch21 con violation shutdown
3 Intercambio de equipos de Gerencia Permitir múltiple aprendizaje MAC (maximum 2) o puertos de acceso flexibles
4 Restricción estricta en equipos de Secretaría Port Security bloqueado a 1 MAC específica. Bloqueo inmediato en caso de cambio
5 Acceso del equipo CCTV en Fa0/24 de cualquier Switch Autorización explícita de la MAC del CCTV en la interfaz Fa0/24 de los switches
6 Portátil IT con acceso universal Registro de la MAC del Portátil IT en el listado permitido o puertos administrativos
7 Sede Cali (Contaduría, Tesorería y bloqueo de externos) Seguridad Sticky en Switch22(2) para usuarios locales; denegación a externos

2. Configuración de Seguridad de Puertos (Port Security)

Punto 1 y 4: Protección General y Secretaría (Bogotá / Cúcuta)

Aplica para las interfaces de acceso estándar conectadas a PCs finales para prevenir conexiones no autorizadas.

! Ingresar a la interfaz o rango de interfaces de acceso
enable
configure terminal
interface range FastEthernet 0/1 - 23
 switchport mode access
 switchport port-security
 switchport port-security maximum 1
 switchport port-security mac-address sticky
 switchport port-security violation shutdown
exit

Punto 2: Protección del Servidor DNS (Switch21 - Cúcuta)

El puerto conectado al servidor DNS se apaga inmediatamente ante cualquier intento de conexión ajena.

enable
configure terminal
interface FastEthernet 0/2   ! Ajustar a la interfaz exacta del ServerDNS
 switchport mode access
 switchport port-security
 switchport port-security maximum 1
 switchport port-security mac-address sticky
 switchport port-security violation shutdown
exit

Punto 3: Equipos de Gerencia (Bogotá)

Para permitir el intercambio entre las sedes de Bogotá sin caer la interfaz, permitimos hasta 2 direcciones MAC registradas.

enable
configure terminal
interface range FastEthernet 0/1 - 2   ! Interfaces conectadas a Gerencia
 switchport mode access
 switchport port-security
 switchport port-security maximum 2
 switchport port-security mac-address sticky
 switchport port-security violation restrict   ! Notifica sin apagar la interfaz
exit

Punto 5: Configuración del Puerto CCTV (Fa0/24) en Todos los Switches

Permite conectar la cámara CCTV en cualquier puerto Fa0/24 asignando estáticamente su dirección MAC.

enable
configure terminal
interface FastEthernet 0/24
 switchport mode access
 switchport port-security
 switchport port-security mac-address <MAC_DEL_CCTV>   ! Ej: 0001.C4A1.B2C3
 switchport port-security violation shutdown
exit

Puntos 6 y 7: Portátil IT y Sede Cali

En el switch de Cali (Switch22(2)), registramos los equipos autorizados de Contaduría y Tesorería mediante sticky.

enable
configure terminal
interface range FastEthernet 0/1 - 2
 switchport mode access
 switchport port-security
 switchport port-security maximum 1
 switchport port-security mac-address sticky
 switchport port-security violation shutdown
exit

3. Configuración de Enrutamiento Dinámico RIPv2

Para interconectar las 3 sedes (Bogotá, Cali y Cúcuta), habilitamos RIP versión 2 y desactivamos el sumarizado automático en los 3 routers.

Router Bogotá (Router5)

enable
configure terminal
router rip
 version 2
 no auto-summary
 network <RED_LAN_BOGOTA>
 network <RED_SERIAL_BOGOTA_CALI>
exit

Router Cali (Router6)

enable
configure terminal
router rip
 version 2
 no auto-summary
 network <RED_LAN_CALI>
 network <RED_SERIAL_CALI_BOGOTA>
 network <RED_SERIAL_CALI_CUCUTA>
exit

Router Cúcuta (Router5(1))

enable
configure terminal
router rip
 version 2
 no auto-summary
 network <RED_LAN_CUCUTA>
 network <RED_SERIAL_CUCUTA_CALI>
exit

4. Comandos de Verificación y Diagnóstico

Tip de Verificación en Packet Tracer:
Ejecuta estos comandos en el CLI para validar que las políticas de seguridad y la tabla de enrutamiento estén operando correctamente.
  • show port-security: Muestra el estado global de seguridad de puerto en el switch.
  • show port-security interface FastEthernet 0/1: Muestra detalles de violaciones, contador de direcciones MAC y estado de la interfaz.
  • show port-security address: Muestra la lista de direcciones MAC aprendidas dinámicamente (sticky) o configuradas estáticamente.
  • show ip route rip: Muestra las rutas aprendidas en los routers a través del protocolo RIPv2.
